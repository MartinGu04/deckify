Spotify currently requires Premium for the owner of a Development Mode app.

About Spotify Development Mode
  • New Spotify apps start in Development Mode, which is meant for personal use.
  • Spotify currently requires the app owner to have Spotify Premium.
  • Spotify currently allows each new developer one Development Mode Client ID.
  • A Development Mode app can authorize up to five Spotify accounts. To use one that isn't the owner's, add it under Users Management in the app's settings.

These are Spotify's rules for Development Mode apps, not Deckify limits.

Find it in your Spotify app's settings, under Basic Information.
