# Development-era Deckify identity (archived)

**What these files were:** `deckify-icon.png` and `deckify-logo.png` were Deckify's identity while it was a private development project
(Phases 1–6): a green "D" with three curved sound lines.

**Why they were retired:** that mark leaned on Spotify's brand elements, Spotify Green and the Spotify icon's waves. A third-party app's
logo must not include or resemble those, so it was never a valid public identity. In Phase 7 it was replaced by the approved Deckify
brand, **B1 · Frame D** (see [`../../README.md`](../../README.md)).

**Status:** the files are kept unchanged for history only.

- Nothing uses them any more: the plugin, the package, the README, docs media and Marketplace artwork don't, and the brand export
  script never reads this folder.
- Tests check that no production file references them or reproduces them.
- Don't use them for anything public.
