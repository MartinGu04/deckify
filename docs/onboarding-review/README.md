# Spotify Account setup: review renders

Renders of the Phase 8 Spotify Account Property Inspector, for reviewing the guided setup before the hardware check. They come from the
real `ui/spotify-account/` page, opened in headless Chromium at 360 px wide, with the plugin's messages simulated (fake Client ID and
display name; no Spotify account involved). They are review material, not product media, and are not shipped with the plugin.
